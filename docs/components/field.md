# Field

A collection of form layout components used to organize labels, descriptions, controls, and validation messages.

The Field component provides consistent spacing, alignment, and accessible form structure.

Nexora UI follows the shadcn/ui Field component conventions.

## Reference

- [shadcn/ui – Field](https://ui.shadcn.com/docs/components/field)

## Usage

Refer to the official documentation for component usage, field layouts, field groups, field sets, orientation, and accessibility details.
