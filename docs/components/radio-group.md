# Radio Group

A radio group component that allows users to select exactly one option from a collection of mutually exclusive choices.

Nexora UI follows the shadcn/ui Radio Group component conventions.

## Reference

- [shadcn/ui – Radio Group](https://ui.shadcn.com/docs/components/base/radio-group)
