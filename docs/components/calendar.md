# Calendar

A calendar component that allows users to view dates and select individual dates or date ranges.

It is useful for date selection, scheduling, booking, and filtering interfaces.

Nexora UI follows the shadcn/ui Calendar component conventions.

## Reference

- [shadcn/ui – Calendar](https://ui.shadcn.com/docs/components/calendar)

## Usage

Refer to the official documentation for component usage, date selection, disabled dates, date ranges, and customization.
