# Input Group

An input group component that combines an input or textarea with additional elements, such as icons, labels, buttons, prefixes, and suffixes.

Nexora UI follows the shadcn/ui Input Group component conventions.

## Reference

- [shadcn/ui – Input Group](https://ui.shadcn.com/docs/components/input-group)

## Usage

Refer to the official documentation for component usage, addons, buttons, text elements, and supported layouts.
