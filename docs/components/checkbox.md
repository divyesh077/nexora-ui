# Checkbox

A checkbox component that allows users to select or deselect an option. It can also be used in forms, preference settings, and multi-selection interfaces.

Nexora UI follows the shadcn/ui Checkbox component conventions.

## Reference

- [shadcn/ui – Checkbox](https://ui.shadcn.com/docs/components/base/checkbox)

## Usage

Refer to the official documentation for component usage, checked states, indeterminate state, and accessibility details.
